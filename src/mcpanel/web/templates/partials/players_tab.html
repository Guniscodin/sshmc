What do OP levels mean?
L1 Spawn protection
Can build and break blocks inside the spawn-protection radius. No extra commands.
L2 Command blocks & cheats
Can use command blocks and most gameplay commands such as /give, /tp, /gamemode, /time and /weather, but cannot manage other players.
L3 Manage players
Everything above, plus /kick, /ban, /op, /deop and whitelist changes.
L4 Full admin
Can run every server command, including /stop and /reload. Only give this to people you fully trust.
